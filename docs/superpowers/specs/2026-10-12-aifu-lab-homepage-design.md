# AIFu Lab 学术主页设计规范

日期：2026-10-12  
状态：已完成对话设计确认，等待书面规范复核

## 1. 项目目标

将 KAI FU 现有个人主页升级为 AIFu Lab（AI-Fused Electromagnetic Design Group）课题组主页。网站首先服务学术同行，其次服务希望了解课题组、申请保研或参加毕业设计的学生。

本阶段以“框架完整、内容真实、便于增长”为目标。网站不以履历数量取胜，而是通过清晰的研究定位、稳定的信息结构、真实科研图像和明确的学生入口建立可信度。

## 2. 品牌与研究定位

- 对外名称：AIFu Lab
- 英文全称：AI-Fused Electromagnetic Design Group
- 中文名称：AI 融合电磁设计课题组
- 负责人：KAI FU，副教授
- 核心定位：人工智能算法赋能的电磁器件设计研究
- 当前研究重点：
  - AI 辅助天线设计
  - 电磁器件参数优化
  - 电磁结构拓扑优化
- 后续拓展方向：
  - AI 辅助滤波器设计
  - AI 辅助功率放大器设计
  - 面向电磁设计自动化的智能 EDA 方法
  - 大语言模型在电磁与 EDA 领域的应用和研究

网站必须区分“当前研究重点”和“未来拓展方向”，避免把计划中的方向写成已经形成规模的成果。

## 3. 语言策略

网站以中文为主。课题组名称、负责人姓名、职称、研究关键词、论文标题及学术外链保留必要英文，便于国际同行识别。页面不提供完整双语切换系统，以免增加当前维护成本；后续若英文内容增长，可在既有模板上增加英文版本。

## 4. 信息架构

网站采用多页面结构，顶部导航包含以下八项：

1. 首页
   - AIFu Lab 定位
   - 负责人简介
   - 近期动态
2. 研究方向
   - 当前重点
   - 未来拓展
3. 团队成员
   - 负责人
   - 在读学生
   - 毕业成员
   - 没有内容的分组不渲染
4. 研究成果
   - 论文
   - 项目
   - 学生成果
   - 支持按年份逐步扩充
5. 教学与毕业设计
   - 当前不宣称已承担课程
   - 展示已开设的毕业设计方向与学生培养信息
6. 招生与合作
   - 保研招生
   - 毕业设计招生
   - 期待的学生背景
   - 合作方向
   - 联系方式
7. 联系我们
   - 隶属大实验室
   - 学院与学校
   - 地址
   - 邮箱
   - 学术主页和外部链接
8. 个人简历
   - 独立保留 KAI FU 的 CV 入口

## 5. 首页内容层级

首页仅保留三层信息：

1. AIFu Lab 品牌横幅与主导航；
2. KAI FU 负责人信息卡与课题组定位；
3. 近期动态列表。

研究方向、成员、成果、教学和招生信息进入独立页面，首页不重复堆叠这些内容。这样既保持首页克制，也使各栏目能随着课题组成长单独扩展。

## 6. 视觉方向

视觉参考 Alex M. H. Wong 教授主页的学院派实验室风格，但不复制其具体页面：

- 深色渐变实验室横幅；
- 以电磁场图形作为课题组视觉识别；
- 明亮绿色作为研究与品牌强调色；
- 蓝色导航与学术链接色；
- 浅蓝色负责人信息卡；
- 清晰的边框和适度阴影；
- 中文正文采用现代无衬线字体，标题可使用克制的衬线字体；
- 去除老式按钮高光、重阴影和拥挤排版；
- 保持足够留白，并适配手机、平板和桌面屏幕。

## 7. 图像策略

图像承担研究解释和可信度表达，不作装饰性堆砌。

- 首页：仅使用课题组电磁场识别图和负责人正式肖像；
- 研究方向：使用真实的电磁场分布、优化流程、器件结构和拓扑演化图；
- 团队成员：使用统一比例和统一裁切方式的人物肖像；
- 研究成果：采用“一张图 + 一个核心结论 + 完整引用或链接”的呈现方式；
- 学生成果：优先使用学生项目的真实结果图、实物图或界面截图；
- 每张信息性图片必须有简短图注和替代文字；
- 没有合适图片的条目采用纯文字布局，不显示破损占位或虚构科研图像；
- 图像在发布前进行尺寸控制和压缩，并启用延迟加载。

## 8. 技术架构

网站采用 GitHub Pages 原生支持的 Jekyll：

- Markdown 负责页面正文；
- YAML 数据文件负责结构化内容；
- Liquid 模板负责布局、条件渲染和列表生成；
- CSS 负责主题、响应式布局和视觉组件；
- 少量原生 JavaScript 仅用于移动端导航等必要交互；
- 不引入 React、Vue、数据库、登录系统或在线表单。

构建数据流如下：

```text
Markdown / YAML 内容
        ↓
Jekyll + Liquid 模板
        ↓
静态 HTML / CSS / JavaScript
        ↓
GitHub Pages /Homepage/ 子路径
```

所有内部链接和静态资源通过 Jekyll 的 `relative_url` 或等效机制生成，确保在 `https://kaiifu.github.io/Homepage/` 下正确工作。

## 9. 内容文件设计

结构化内容按以下方式维护：

- `_data/site.yml`：课题组名称、负责人、隶属关系、地址、邮箱和外部链接；
- `_data/members.yml`：负责人、在读学生和毕业成员；
- `_data/news.yml`：近期动态；
- `_data/outputs.yml`：论文、项目和学生成果；
- Markdown 页面：研究方向、教学与毕业设计、招生与合作、联系信息；
- `_layouts/`：站点级页面布局；
- `_includes/`：横幅、导航、页脚、成员卡、成果条目和动态条目；
- `assets/`：样式、脚本、图片和 CV 文件。

模板根据数据内容决定是否渲染分组。缺少的非必要字段直接省略；缺少的关键事实在发布版本中不显示猜测值。现有主页中可确认的真实资料优先迁移，无法确认的信息保持未发布状态，待用户后续补充。

## 10. 页面组件

- 品牌横幅：AIFu Lab、中英文全称、电磁场识别图、隶属单位；
- 主导航：八个栏目，移动端折叠；
- 负责人信息卡：正式肖像、姓名、职称、研究定位和学术链接；
- 动态条目：日期、标题、简述和可选链接；
- 研究方向卡：真实科研图像、方向名称、当前状态和简短说明；
- 成员卡：肖像、姓名、身份、研究方向和可选个人链接；
- 成果条目：年份、类别、标题、作者或参与者、图像、摘要和外部链接；
- 招生信息块：保研、毕业设计、背景要求、合作方式和联系入口；
- 页脚：课题组、隶属单位、版权和更新时间。

## 11. 响应式与可访问性

- 手机端导航折叠，页面切换保持键盘可操作；
- 人物卡、研究卡和成果条目在窄屏切换为单列；
- 正文不出现横向滚动；
- 颜色对比度满足日常阅读需求，信息不只依赖颜色表达；
- 链接带有可见文字，不使用只有图标且无说明的入口；
- 页面使用语义化标题层级、导航区域和内容区域；
- 信息性图片包含替代文字，装饰图片使用空替代文字；
- 键盘焦点样式清晰可见。

## 12. 容错与内容真实性

- 空成员分组、空成果分类和空动态列表不渲染；
- 图片缺失时自动采用纯文字布局；
- 外部链接在数据层可选，缺失时不显示按钮；
- 不在公开页面显示“即将上线”、空卡片或虚构成果；
- 教学页面只描述已经开设的毕业设计，不暗示已承担课程；
- 未来研究方向使用“计划拓展”“探索”等措辞，与已有成果明确区分。

## 13. 验收标准

实现完成后应满足：

- Jekyll 构建无错误；
- 八个导航入口均可访问；
- GitHub Pages `/Homepage/` 子路径下无错误资源路径；
- 现有主页中可核实的资料已迁移，未核实内容未被猜测补全；
- 空分组和空字段不产生视觉占位；
- CV 和已配置的外部链接有效；
- 360 px、768 px 和桌面宽度下布局可读且无横向滚动；
- 页面键盘导航、标题层级、图片替代文字和颜色对比度通过基本检查；
- 图片经过压缩并启用合理的延迟加载；
- 首页只包含品牌、负责人和近期动态三层信息；
- 研究页面明确区分当前重点与未来拓展；
- 教学页面准确体现“毕业设计已开设、课程尚未承担”；
- 招生页面明确覆盖保研与毕业设计两类学生。

## 14. 非目标

本轮不包含：

- 完整中英文双语切换；
- 新闻后台或内容管理系统；
- 登录、留言、申请表或数据库；
- 论文自动抓取；
- 复杂动画和沉浸式三维电磁可视化；
- 对外发布任何未经用户确认的个人、学生或科研信息。

这些能力可在课题组内容规模和维护需求增长后再评估。
